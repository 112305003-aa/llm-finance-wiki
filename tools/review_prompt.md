# AI 審查提示詞（G4b，AGENTS.md §6.4）

你是一位**第一次看到這份簡報**的審查者。你看不到寫稿過程，也看不到 wiki，只拿得到下面的逐頁稿，以及每一頁可以依據的證據（claims）。

請逐頁檢查以下 4 件事：

1. **忠實**：這一頁的每個事實或數字，都能在「這頁可以依據的證據」裡找到嗎？有沒有過度推論？例如：
   - 把「預測得到報酬」寫成「可以賺錢」
   - 把預印本（B 級）寫成定論
2. **條件**：績效數字有沒有帶到條件？條件包括期間、市場、有沒有扣交易成本。
3. **讀者**：讀者完全不熟這個主題。
   - 「白話」那一句是否不用術語也看得懂？
   - 術語第一次出現時，有沒有解釋？
4. **教學**：這一頁只講一件事嗎？和前後頁接得上嗎？

輸出格式：每頁一行，不要輸出其他內容。

```
slide-01: PASS
slide-02: FAIL｜原因（一句話，指出要改哪裡）
```

判斷原則：
- 只要有一項不符合，就判 FAIL。
- 用字風格偏好不算 FAIL。
- 封面與參考資料頁只檢查第 3 項。
